معاملات خيبر — حزمة موحدة

هذه الحزمة تحتوي على index.html موحد من نسخة DNS + الجواهر + الأيقونة + الصندوق، مع ملفات الأصول المتاحة. لا يوجد قسم أحاديث داخل الصفحة الرئيسية.

مهم عند النشر على GitHub Pages:
1) فك ضغط الحزمة على جهازك.
2) افتح مستودع KhAyBaR-StOrE واضغط Add file ثم Upload files.
3) اسحب جميع الملفات والمجلدات المستخرجة دفعة واحدة إلى المستودع، مع الحفاظ على بنية المجلدات. يجب أن يكون index.html في جذر المستودع، ومجلد assets بجانبه.
4) اضغط Commit changes مرة واحدة بعد رفع كل الملفات.
5) لا ترفع نسخ index.html المتعددة ولا ترفع مجلد الحزمة نفسه بدل محتوياته. لا تحذف ملفات من المستودع.

تم فحص سلامة أرشيف ZIP، لكن لا يمكن ضمان تشغيل الموقع المنشور دون اختباره على GitHub Pages.
